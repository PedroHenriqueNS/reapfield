## [Unreleased]

Human-written summary of breaking changes in this cycle — versioning itself is owned by
release-please, generated from the commits below.

### Breaking

- **`--strict` now exits 1 on a partial `--many` result**, not only when a field was found
  on zero records. Previously a field found on some but not all records was silently
  accepted under `--strict`; now it is a miss, with reason `"found on N of M records"`.
- **Private, loopback and link-local addresses are now blocked by default on the CLI**, not
  only over MCP — including addresses reached via a redirect. Anyone scraping `localhost`
  or a LAN host needs the new `--allow-private` flag. The default flipped because a redirect
  target is chosen by the server you were pointed at, not by the person who typed the URL —
  so it deserves no more trust than a model-supplied MCP URL.
- **Redirects are now followed by hand, capped at 5 hops**, with robots.txt, the
  gated-platform guard, rate limiting and the private-address check re-applied at every hop.
  Previously these gates ran once, against the original URL only.
- **Removed the `-v`/`--verbose` CLI flag.** It was never wired to any behavior.

### Added

- The MCP `scrape` tool gained `no_llm`, `max_llm_calls`, `no_cache`, `cache_ttl`, `scroll`
  and `paginate` parameters, matching the cost and fetch controls the CLI already had.

## [0.1.0] - 2026-08-05

Initial release.

### Added

- Extraction pipeline that tries the free paths before paying for an LLM:
  JSON-LD, OpenGraph and `<meta>`, `__NEXT_DATA__`, `__NUXT__`, inline JSON,
  then config-pinned selectors, then the selector cache.
- Selector derivation via a single batched Anthropic call, cached per field per
  domain so steady-state cost is zero LLM calls.
- Lazy invalidation: a cached selector is dropped and re-derived when it matches
  nothing or yields a value that fails its declared type. There is no TTL.
- Automatic cardinality detection, with `--one` / `--many` to force it. A
  conflict is an error, never a silent truncation.
- Fetch layer with httpx-to-Playwright escalation, robots.txt compliance,
  per-domain rate limiting, retries with backoff, and anti-bot detection that
  stops rather than evades.
- `reapfield` CLI with json, jsonl and csv output.
- `reapfield-mcp` stdio MCP server sharing one core with the CLI, with an SSRF
  trust boundary that resolves hostnames before deciding.
- Adapter seam with zero adapters, and a guard that refuses to scrape the
  logged-out HTML of gated platforms.
